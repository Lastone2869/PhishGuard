# Models Directory

This directory stores trained model artifacts and vectorizers produced by the training pipeline:

- `core_model.pkl`: Trained Logistic Regression classifier on word & character n-gram TF-IDF.
- `tfidf_vectorizer.pkl`: Fitted scikit-learn TF-IDF vectorizer (word + char n-grams).
- `baseline_model.pkl`: Multinomial Naive Bayes baseline model.
